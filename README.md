# Xray Selector

Панель управления Xray/XKeen для роутеров Keenetic: мониторинг и автовыбор серверов, маршрутизация по сервисам и устройствам.

Работает прямо на роутере (Entware + [XKeen](https://github.com/Skrill0/XKeen)), один файл без зависимостей, веб-интерфейс на русском. Подходит для arm64, mipsel и mips.

## Что умеет

- **Сторож** — каждые 15 секунд проверяет, открываются ли через активный сервер YouTube, Instagram, Telegram, WhatsApp и другие сервисы, меряет скорость и сам переключается на лучший сервер. Во время игры или звонка не переключает без необходимости.
- **Баллы серверов** — доступность, отклик, скорость, «заморозки», разброс отклика и надёжность по часам суток.
- **Правила** — каталог из 70 сервисов: «через VPN», «без VPN — через провайдера» или как обычно. Три общих режима: выборочно, почти всё через VPN, полностью через VPN. Свои сайты, «Почему не открывается сайт?», отключение QUIC.
- **Устройства** — свой режим для каждого устройства, временный режим («на 1 час всё через VPN»), детское расписание, блокировка рекламы.
- **Сеть** — провайдеры Keenetic, DNS с историей за сутки, короткие обрывы интернета.
- **Подписка** — обновление серверов с проверкой и откатом, срок и остаток трафика, кнопка «Написать в поддержку».
- **Резерв** — если не работает ни один сервер подписки, переключение на WireGuard/OpenVPN/прокси-подключение Keenetic.
- **Telegram** — сообщения об авариях и смене сервера (уровни «Только аварии / Важное / Всё»), управление из лички.
- **Безопасные правки** — любое изменение конфигов проверяется `xray -test`, перед записью делается резервная копия, если Xray не поднялся — откат.
- **Мастер первого запуска**: проведёт по настройке шаг за шагом.

## Установка

> **Впервые работаете с роутером через командную строку?** Откройте [пошаговую инструкцию](INSTALL.md) — там всё с нуля и разобраны частые проблемы.

Нужны Keenetic с Entware и установленный XKeen. По SSH на роутере:

```sh
curl -fsSL -o /tmp/xs.tgz https://github.com/Zlobniy2kx/xray-selector/releases/latest/download/xray-selector.tar.gz
tar xzf /tmp/xs.tgz -C /tmp
sh /tmp/xray-selector/install.sh
```

Панель откроется на `http://адрес-роутера:9091`, например `http://192.168.1.1:9091` (точный адрес установщик покажет в конце). Дальше поможет мастер.

Обновление — в самой панели: о новой версии она сообщит сама, а вручную — «Настройки → Основные → Обновления».

Удаление (XKeen и конфиги Xray не трогаются):

```sh
sh /opt/share/xray-selector/install.sh --uninstall
```

## Сборка

Go 1.24, только стандартная библиотека:

```sh
./build.sh
```
